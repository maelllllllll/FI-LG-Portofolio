# Dépose tes fichiers ici

Tout ce que tu mets dans ce dossier me parvient. Je l'optimise, je le range
dans la bonne rubrique, puis je vide ce dossier — les versions allégées
partent dans `public/images/`.

Pas besoin de renommer ni de trier : les noms d'origine me suffisent pour
reconnaître de quoi il s'agit. Un sous-dossier par rubrique aide quand même,
si c'est simple pour toi :

    uploads/madura/          photos de la collaboration Madura
    uploads/collections/     défilés et campagnes, un dossier par collection
    uploads/imprimes/        les imprimés
    uploads/presse/          parutions

## Deux limites de GitHub à connaître

**100 Mo par fichier, sans exception.** Les fichiers de production du Drive
les dépassent largement : les TIF d'imprimés vont de 300 Mo à 1,3 Go, et le
PSD d'Appolonie fait 340 Mo. Ceux-là ne passeront pas. Il faut les exporter
en JPG avant — qualité 80 suffit, la différence est invisible à l'écran et
le poids est divisé par vingt.

**Le dépôt garde tout, pour toujours.** Un fichier supprimé reste dans
l'historique. Mieux vaut donc ne déposer que ce qu'on compte vraiment
utiliser, plutôt que de vider un dossier entier « au cas où ».
